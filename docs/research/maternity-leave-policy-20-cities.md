# 中国20个重点城市产假审批政策研究（MVP）

> 核验基准日：2026-08-11  
> 用途：企业 HR / leave admin 的产假资格判断、天数计算与政策复核。  
> 边界：本文只处理女职工生育产假及难产、多胞胎等直接加假；流产假、陪产假、育儿假、哺乳假、生育津贴支付口径不在首版计算范围内。政策结论来自官方一手来源，但不替代主管部门意见或个案法律意见。

## 2. 全国共同底座

国务院《女职工劳动保护特别规定》（国务院令第619号）第七条规定：正常生育98天（其中产前可休15天）；难产增加15天；多胞胎每多生育1个婴儿增加15天。该规定自2012年4月28日公布施行，适用于境内国家机关、企业、事业单位、社会团体、个体经济组织及其他社会组织和女职工。[司法部官方文本](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzfgjd/201205/t20120508_151657.html)

《中华人民共和国人口与计划生育法》第二十五条只确立“符合法律、法规规定生育子女的夫妻，可以获得延长生育假的奖励或者其他福利待遇”，具体天数由地方规定。[中国人大网现行文本](https://www.npc.gov.cn/npc/c2/c30834/202109/t20210903_313395.html)

全国底座的可执行公式：

```text
national_days = 98
                 + (dystocia ? 15 : 0)
                 + max(infant_count - 1, 0) * 15
```

注意：第619号令没有统一定义“难产”的医学范围，也没有在第七条写明周末/法定节假日口径；计算器必须优先读取地方实施解释。没有地方解释时，不应把“难产”仅凭员工勾选自动认定，应要求医疗机构材料。

## 4. 已核验辖区详表

### 4.1 天津

- 规则：98 + 60 = 158天；难产+15天；多胞胎每多1婴+15天。
- 难产定义：产钳助产、胎头吸引术、臀位助娩及有医学指征的剖宫产；仅因社会或个人因素自行要求的剖宫产不在该实施口径内。
- 计算：生育假（产假）为自然日，包括法定节假日和休息日；一般连续使用，可由单位与职工协商。
- 版本：《天津市人口与计划生育条例》2021年11月29日修改并施行；《关于婚假生育假（产假）陪产假育儿假护理假等假期休假的实施办法》（津政办规〔2022〕9号）有效。
- 来源：[天津市政府实施办法第3、5、13条](https://www.tj.gov.cn/zwgk/szfwj/tjsrmzfbgt/202205/t20220520_5886520.html)、[天津市卫健委2024政策问答第6—9问](https://wsjk.tj.gov.cn/ZMHD5990/wdk/wdzt/zcwdzt/202412/t20241220_6811651.html)、[天津市人社局难产认定问答](https://hrss.tj.gov.cn/WZWSREL3poZW5nbWluaHVkb25nL3dkay96Y3dkLzIwMjQxMC90MjAyNDEwMjNfNjc1OTQwMi5odG1s)。

### 4.2 陕西（西安）

- 通常规则：98 + 60 = 158天。
- 条件加假：参加孕前检查并取得指定县级以上医疗卫生机构证明，+10天；生育三孩，在前款产假基础上再+15天。
- 难产/剖宫产：+15天；多胞胎每多1婴+15天。
- 计算：产假和延长产假一次性休完、原则不拆分；产假含公休日和国家法定假日，但不含所在行业或系统内部另行规定的假期。
- 生效：现行《陕西省人口与计划生育条例》于2022年5月25日公布施行；新增加的产假自当日生效。
- 公式：`98 + 60 + 孕前检查10 + 三孩15 + 难产15 + (婴儿数-1)*15`，各条件独立记录，不要把孕前检查加假默认发给所有员工。
- 来源：[陕西省条例第45条](https://www.shaanxi.gov.cn/zfxxgk/zcwjk/dfxfg/202402/t20240226_2320584.html)、[省卫健委实施三孩政策指导意见第（五）（六）项](https://www.shaanxi.gov.cn/zfxxgk/zcwjk/szfbm_14999/qtwj_15009/202208/t20220831_2249166.html)、[陕西省实施女职工劳动保护特别规定第14条](https://www.shaanxi.gov.cn/zfxxgk/fdzdgknr/zcwj/nszfgz/202208/t20220804_2233087.html)。

### 4.3 河南（郑州）

- 条例文字：除国家产假外增加“三个月”；郑州市政府/医保的现行公开执行口径明确为地方奖励90天、合计188天。
- 难产+15天；多胞胎每多1婴+15天，来自国家第619号令。现行河南条例没有缩减该国家权利。
- 计算口径风险：条例写“月”、郑州待遇实践写“90天”。为了输出唯一日期，MVP按郑州官方188天口径计算；同时在复核逻辑中显示“省条例原文为三个月，郑州官方实施按90天”。
- 连续性：未找到河南省现行条例对周末/法定节假日的单独排除条款。可按产假连续自然日作为运营默认，但首版输出保留低风险提示。
- 生效：现行《河南省人口与计划生育条例》为2021年11月27日第六次修正，自公布之日起施行。
- 来源：[河南省条例第25条（郑州市卫健系统官方全文）](https://hj.jiceng.zhengzhou.gov.cn/021005001/7984833.jhtml)、[郑州市政府关于延长90天、合计188天的官方答复](https://public.zhengzhou.gov.cn/D1101X/8738656.jhtml)、[郑州医保提案答复](https://public.zhengzhou.gov.cn/D1102X/7791905.jhtml)。

### 4.4 湖南（长沙）

- 规则：98 + 60 = 158天；难产+15天；多胞胎每多1婴+15天。
- 版本：现行《湖南省人口与计划生育条例》于2021年12月3日公布施行，第16条规定增加60天；《湖南省女职工劳动保护特别规定》（省政府令第298号）第8条把98、难产、多胞胎和奖励60天写在同一条。
- 计算口径：2016年省卫计委应用解释曾明确增加产假连续计算、包括法定节假日和双休日，但该文件标注时效截至2021-06-24，早于现行条例。现行条例延续相同60天政策，却未找到新的同层级计算解释；因此MVP可按连续自然日计算，同时显示“口径沿用、建议争议个案向长沙人社/卫健复核”的低风险提示。
- 来源：[湖南省条例第16、33、34条](https://www.hunan.gov.cn/hnyw/zwdt/202112/t20211204_21236900.html)、[湖南省女职工劳动保护特别规定第8条](https://www.hunan.gov.cn/hnszf/xxgk/zfgz/202110/20737345/files/3cca9bb233b34dd590c5ab55d2e1a019.pdf)、[省政府/省卫健委确认合计158天](https://www.hunan.gov.cn/hnszf/hdjl/wxszsjh/xjgs/202211/t20221122_100062140.html)、[2016应用解释（仅作历史口径证据）](https://www.hunan.gov.cn/xxgk/wjk/szbmwj/201605/t20160525_5259520.html)。

### 4.5 安徽（合肥）

- 规则：98 + 60 = 158天；难产或实施剖宫产+15天；多胞胎每多1婴+15天，特殊增加可与158天叠加。
- 计算：原则连续；**包含休息日，但不包含国家法定休假日**。这是20城中必须单独实现的日历算法，不能简单做“开始日+天数-1”。
- 版本：现行《安徽省人口与计划生育条例》于2021年11月19日修订，2022年1月1日起施行；省卫健委皖卫人口家庭秘〔2021〕325号给出具体计算口径。
- 风险：实施意见写“国家法定休假日”，并未明确调休形成的连休日。MVP只排除《全国年节及纪念日放假办法》规定的法定节日本日（2025年起共13天），周末和调休休息日仍计入；输出中说明该算法假设。
- 来源：[国家法律法规数据库的安徽条例](https://flk.npc.gov.cn/detail?fileId=&id=ff8081817dc2ae9c017dc610f0840730&title=%E5%AE%89%E5%BE%BD%E7%9C%81%E4%BA%BA%E5%8F%A3%E4%B8%8E%E8%AE%A1%E5%88%92%E7%94%9F%E8%82%B2%E6%9D%A1%E4%BE%8B&type=)、[安徽省卫健委指导意见官方镜像](https://wsjkw.tl.gov.cn/tlswsjkwyh/c00010/pc/content/content_1686672897484840960.html)、[淮南市政府逐项复述省级计算口径](https://www.huainan.gov.cn/zmhd/wdzsku/1260273037.html)、[六安市卫健委2024答复](https://www.luan.gov.cn/content/article/10516270)。

### 4.6 山东（青岛）

- 规则：98 + 60 = 158天；难产+15天；多胞胎每多1婴+15天。
- 计算：国家法定节假日、休息日均计入产假；即连续自然日。
- 版本：现行《山东省人口与计划生育条例》于2025年1月18日修改并施行，第26条保留女职工增加60天；同日鲁卫人口家庭字〔2025〕3号明确假期计算。
- 来源：[泰安市卫健委发布的现行条例解释及正式文本入口](https://wjw.taian.gov.cn/art/2025/1/23/art_45778_10321548.html)、[山东省三部门指导意见官方PDF镜像](https://ws.zibo.gov.cn/gongkai/channel_c_5f9fa491ab327f36e4c13061_n_1605682450.3131/doc_67a5b11e0c81719cbf7171e4_c40bf8efdc4f89fdb726fece655ac213.pdf)、[山东省女职工劳动保护办法第12条](https://hrss.zibo.gov.cn/art/2019/2/15/art_8208_1616839.html)、[青岛市政府对158天及特殊增加的适用说明](https://www.qingdao.gov.cn/zwgk/xxgk/sfj/flxx/fwgl/202011/t20201123_2615667.shtml)。

### 4.7 福建（厦门）

- 条例不是“98+固定奖励天数”，而是直接规定女方产假总期为 **158至180天**，区间内由用人单位与申请人协商/由用人单位规定，最低不得少于158天。计算器必须增加“单位确定的福建产假天数”字段；没有该字段只能输出158—180天范围，不能声称唯一日期。
- 难产重大风险：福建省人社厅2025年政策问答明确，按国家第619号令的98天口径，难产可+15；但按福建条例执行158—180天产假时，难产**不再增加**。因此法定最低结果不能机械写成“158+15”。用人单位可以制定更有利规则，但那属于单位规则。
- 多胞胎重大风险：国家第619号令明文每多1婴+15天，但福建条例以总区间表达，现行省级公开问答只明确了难产，没有找到同等明确的多胞胎叠加答复。首版应进入人工复核，而不是自动叠加或自动拒绝。
- 周末/节假日：现行省级条例未写明产假是否排除，未找到省人社/卫健面向全省的现行一手解释。通常实践按连续自然日，但首版必须显示“口径未被现行一手文件明确”的风险。
- 版本：现行《福建省人口与计划生育条例》于2022年3月30日修改并同日施行，第24条；《福建省女职工劳动保护条例》2020年3月20日通过，第13条同样规定158—180天。

## 5. 计算器规则

### 5.1 通用日期约定

1. 员工输入的产假开始日为第1天。
2. 纯自然日规则：`最后休假日 = 开始日 + 总天数 - 1天`；`预计返岗日 = 最后休假日 + 1天`。
3. “排除法定休假日”规则：从开始日逐日遍历；周末仍计数，只跳过法定节日本日；计满应休天数的当日为最后休假日。
4. 分段规则：先计算国家98天和特殊加假，再从下一日计算地方延长段；每段使用本辖区规定的日历口径。
5. 难产和多胞胎同时存在时，除福建风险规则外，两项累计；双胞胎只增加一次15天，三胞胎增加两次共30天。
6. 输出必须同时显示最后休假日（含）和预计返岗日，避免把“到某日”理解成返岗日。

### 5.2 必填/条件输入

```text
work_city                 工作城市
leave_start_date          产假开始日
birth_date                实际生育日
expected_birth_date       尚未生育时的预产期；浙江产前起休时必须提供
dystocia                  是否有可接受的难产医学证明
infant_count              同次生育婴儿数，默认1
birth_order               胎次；浙江、陕西等条件规则需要
lawful_birth_confirmed    是否满足当地延长生育假条件
prenatal_exam_proof       陕西孕前检查证明
employer_policy_days      福建用人单位在158—180内确定的天数
pure_breastfeeding_proof  四川爱婴医院纯母乳喂养证明
optional_leave_approval   北京额外1—3个月、四川三孩+30日等单位同意材料
couple_leave_reallocation 广州夫妻间奖励假调整及单位同意材料
```

### 5.3 不允许自动给唯一日期的情形

- 城市或适用辖区无法识别；
- 福建未提供单位确定的产假总天数；
- 福建多胞胎，单位制度和主管部门口径均未提供；
- 四川案件未取得当地关于90天生育假节假日计算的可执行口径；
- 四川主张纯母乳喂养增加“一个月”，但未确认按月计算的起止边界；
- 浙江在产前开始休假但未提供实际/预计生育日；
- 浙江多胞胎，未取得当地经办部门对最终总数的确认；
- 员工主张难产但没有当地规则认可的医疗材料；
- 生育日期跨越政策新旧版本，且当地过渡条款不能确认；
- 员工生育是否满足地方“符合法律法规规定”条件存在争议；
- 单位制度优于法定标准但未作为结构化输入。

## 7. 质量与更新机制

- 每条规则保存：`jurisdiction`、`effective_from`、`effective_to`、`source_url`、`source_title`、`article`、`verified_at`、`risk_level`。
- 城市只映射政策辖区，不复制省级规则；省级政策变更时一次更新覆盖多个城市。
- 每季度检查一次官方人大、政府、卫健、人社页面；生育政策修法消息触发即时复核。
- 历史审批按生育日/过渡条款调用历史版本，不能拿最新政策反推旧案例。
- 生育津贴天数不等于产假天数；首版输出不得用医保支付天数替代劳动休假天数。
- 官方链接失效时保留文件名、文号、条款和官方镜像，并将记录标为“链接待修复”，不能静默换成商业网站。

## 8. 目前的关键风险结论

1. **不能把所有城市统一成自然日**：上海、江苏、安徽存在法定节假日特殊处理。
2. **不能把所有地方写成158天**：河南郑州188天；陕西有条件加假；福建为158—180区间；四川现行规则已更新。
3. **不能把剖宫产在全国一律当难产**：天津排除无医学指征、仅个人要求的剖宫产；各地认定材料不同。
4. **不能把生育津贴支付期当产假期**：两者来源和承担主体可能不同。
5. **福建不适合首版全自动审批**：总天数和特殊情形均需要单位制度/主管部门口径参与。
